# SpinDoctor Qwerty (Zed)

SpinDoctor is a **classical** quantum-circuit simulator (FP64 on your computer, SpinDoctor 3.1.2 parity). It is not a quantum computer.

1. Install Python 3.8 or newer (standard library only; NumPy is optional).
2. Set `engine` below to the **absolute** path of `engine/scripts/spindoctor_mcp.py` inside the folder you installed this extension from.
3. Optional: `python` (interpreter) and `workspace` (where TXT/PDF/JSON/CSV reports are written).

Then open the Agent Panel and ask: "show the SpinDoctor functions".
